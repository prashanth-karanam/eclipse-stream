# Eclipse Stream

Eclipse is a sleek, highly-responsive cinematic tracker for Movies, Series, Anime, and Manhwa. 
Built with an advanced data-aggregation architecture and a beautiful modern user interface, Eclipse lets you seamlessly discover and log all your favorite titles.

## Features
- **Infinity Matrix**: Discover new shows across all categories with an endless immersive UI.
- **Insights Hub**: Get incredibly detailed analytics on your watch time and reading history. Breakdowns by genre, progress, and type.
- **Universal Search**: Seamlessly pull titles from TMDB, Jikan (Anime), and MangaDex.
- **Cloud Sync**: Optional Firebase authentication lets you securely back up your watchlist to the cloud.

## Live Demo
Check out the live app here: [https://eclipse-stream.web.app](https://eclipse-stream.web.app)

## Local Setup
1. Clone the repository.
2. Serve the directory using any local web server (e.g. `npx http-server`).
3. Enjoy the cinematic experience!
